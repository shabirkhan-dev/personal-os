## What

The owner shared Bruno Delorence's Dot timer (MIT) and asked for it on the boxing timer and in
the other areas that time something.

## Done

- `DotTimer` (components/ui): a Reanimated port. 21 LEDs, one shared 36-frame counter on the UI
  thread, 1.2 s sweep; paused it holds and dims; reduced motion holds a half-lit frame. Fixed-width
  figures, m:ss and h:mm:ss. Tap to start or pause, hold 600 ms to reset (pill presses in);
  screen readers get the time in words, a Reset action and announcements. Licence and credit in
  the file header.
- Tokens: `timerPill`, `timerEdge`, `timerInk`, `ledRed/Amber/Green/Blue/White`.
- Used for: boxing rounds (replaces the ring; red work, green rest; hold restarts), the live
  workout rest timer (blue) and timed sets (amber), cook-mode step timers (amber, green when up),
  Quran recitation (green; hold restarts) and the career 30-minute skill block (blue).

## Validation

- mobile `bun test` 332 pass (formatters tested in `lib/dot-time.test.ts`); typecheck and oxlint
  clean.
- Web export: boxing timer running (lamp frames advance), paused (dims, freezes).
