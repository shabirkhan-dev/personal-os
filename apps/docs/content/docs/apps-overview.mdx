## `apps/mobile`

The Personal OS app: Expo Router, Reanimated and Zustand, styled with `StyleSheet` and
`@personal-os/tokens` (Figma Kit v2). Onboarding v5 runs first, then the home screen.

## `apps/docs`

Fumadocs-powered documentation site for onboarding, architecture, and workflows.

## `apps/nest-api`

NestJS API: sign-in and sessions, profile and avatar, and the onboarding answers, backed by
PostgreSQL through Drizzle ORM. Module data (expenses, meals, workouts) stays on the phone; see
[Product System Design](/docs/product-system-design).

## `apps/ai-api`

FastAPI service for LLM-assisted workflows. The Nest API proxies it; LLM keys are never exposed to clients.

## `apps/web`

The public landing page: a Next.js static export served by Cloudflare Workers, with a small
Worker for launch-day sign-ups. See `apps/web/README.md`.

## Cross-app strategy

- Keep domain boundaries explicit.
- Share contracts and utilities through packages.
- Evolve each app independently while maintaining one quality bar.
