## `apps/web`

Next.js web frontend with shared design primitives and Tailwind-based styling.

## `apps/mobile`

Expo Router mobile app styled with Uniwind (Tailwind `className` for React Native) and shared workspace conventions.

## `apps/docs`

Fumadocs-powered documentation site for onboarding, architecture, and workflows.

## `apps/nest-api`

NestJS production API: auth, tenancy, users, billing, MFA and passkeys, backed by PostgreSQL through Drizzle ORM.

## `apps/ai-api`

FastAPI service for LLM-assisted workflows. The Nest API proxies it; LLM keys are never exposed to clients.

## `apps/rust`

Rust (Axum) service for performance-sensitive or systems-level workloads.

## Cross-app strategy

- Keep domain boundaries explicit.
- Share contracts and utilities through packages.
- Evolve each app independently while maintaining one quality bar.
