Personal OS is a mobile-first life app. This site documents the monorepo behind it: the Expo app,
the NestJS API, the FastAPI AI service and the shared tooling.

## What is in the repo

- Monorepo by default with Turborepo workspaces (`apps/*`, `packages/*`)
- Bun-first package and task management
- Shared design tokens (`@personal-os/tokens`) and TypeScript config
- Built-in quality gates with oxlint, oxfmt and Lefthook
- Expo mobile app, Nest API, FastAPI AI service and this docs site
