Personal OS is a personal life operating system for routines, finance, personal care, food,
fashion, and the small decisions that shape a day. This site documents the software that powers
it: how to run the repo, how the apps fit together, and what is safe to build next.

## What is real today

| Surface | Current state |
| --- | --- |
| Platform | Bun + Turborepo, Next.js web, Expo mobile, NestJS API, Fumadocs, CI, and Docker |
| Identity | Auth, profiles, sessions, passkeys, MFA, and social sign-in spine |
| Product | Routines and finance APIs are ready; care, food, and fashion are planned |
| Intelligence | Nest owns the public AI proxy; `apps/ai-api` is an internal beta service |

The [production roadmap](/docs/production-roadmap) explains the sequence. The [API status board](/docs/backend-api)
is the contract for web and mobile callers.

## Source of truth

- `plan.md` — product vision, domains, and milestones.
- `AGENTS.md` — repository rules for humans and coding agents.
- `DESIGN.md` — visual and interaction quality bar.
- `.agents/` — team notes, work requests, and cross-team coordination.
- `apps/docs/content/docs/backend-api.mdx` — API readiness and caller contracts.

If implementation and a planning page disagree, verify the code and update the relevant source of
truth in the same change. Documentation should help a new developer make the right decision without
having to reconstruct the project history.
