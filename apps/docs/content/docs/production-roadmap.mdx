The engineering roadmap for Personal OS. The board in `.agents/board/` tracks individual cards;
this page is the summary. Architecture context: [Product System Design](/docs/product-system-design).

## Built

### Foundation

- Bun + Turborepo monorepo, oxlint/oxfmt, Lefthook hooks, architecture and naming checks, CI,
  CodeQL and Dependabot.
- `@personal-os/tokens`: Figma Kit v2 colours, spacing, radii and text styles, light and dark.

### Mobile app

- Onboarding end to end: voice input, saved progress, reminders, plan reveal and sign-in.
- Today: Overview plus module Homes for Finance, Workout, Skincare and Food (with Recipes), and
  Profile, all on what the person enters. Module data is stored on the phone
  ([ADR 0001](/docs/architecture/adr-0001-on-device-module-data)).
- Ask bar that parses typed lines into module entries.
- Career module: pipeline, follow-ups with AI-drafted nudges, job links read by AI with a halal
  reading, interview prep with flashcards, and a 30-minute-a-day skill path.
- Offline-first record store on the phone with sync to the API
  ([ADR 0002](/docs/architecture/adr-0002-offline-first-sync)).
- EAS development builds, EAS Update channels and a one-command APK build.

### API and services

- Email-code sign-in with rotating refresh sessions; password, magic-link, TOTP, passkey and
  Google flows kept for later use.
- Profile and avatar endpoints; onboarding answers stored and synced.
- AI service (FastAPI) behind the Nest proxy, with a mock provider for tests.
- Landing page on Cloudflare Workers with a launch waitlist.

## Next

Roughly in order; each item becomes board cards.

1. **Google and Apple sign-in on mobile** (pos-12).
2. **Remaining modules**: Faith next, then Daily life and Fashion, on the record store.
3. **Move Finance, Workout, Skincare and Food onto the record store** so everything is synced.
4. **Files on Cloudflare**: avatars and photos in R2; videos streamed from Google Drive.
5. **Insights**: AI over a per-module, opt-in daily digest, shown in the Insights tab.
6. **Production hardening**: Redis-backed rate limits, structured request logs and error
   tracking, and real deploy steps in `cd.yml` (it is still a template).
7. **Desktop app** on the same record store and sync.

## Engineering rules

- Every API change updates [Backend API](/docs/backend-api) in the same commit.
- Schema changes ship with a generated migration; no schema push outside local development.
- Pure logic gets unit tests; screens handle loading, empty and error states.
- No secrets in the app bundle; LLM keys stay in the AI service.
- `bun run preflight` passes before a push.
