Consistency, fast feedback, and automation across TypeScript and Bash.

## Cross-repo (Tier 1)

| Layer | What we use |
|-------|-------------|
| **Git hooks** | Lefthook: format, lint, typecheck, large-files, secrets, commit-msg (see `scripts/git-hooks/`) |
| **Task runner** | Bun scripts via `bun run <task>` (see root `package.json`) |
| **Editor consistency** | `.editorconfig`: LF, indent, charset, final newline |
| **CI** | `.github/workflows/ci.yml`: split quality gates (lint, typecheck, build, coverage tests) on push/PR to `main` |
| **CD** | `.github/workflows/cd.yml`: staged deploy workflow template (staging on `main`, production on version tags) |
| **Dev Container** | `.devcontainer/`: reproducible env (Bun, shell tools). Reopen in Container; see `.devcontainer/README.md` |
| **Security** | `.github/workflows/security.yml`, CodeQL and Dependabot |

## Per-language

| Language | Lint / format | Test / types |
|----------|----------------|--------------|
| **TS/JS** | oxlint (lint), oxfmt (format) | tsc (typecheck), Vitest (API, against Postgres), `bun test` (mobile) |
| **Bash** (`scripts/`) | shellcheck, shfmt | — |

## One-command surface

From repo root:

- **`bun run format`** — oxfmt + scripts (shfmt)
- **`bun run lint`** — Turbo lint (oxlint) + shellcheck over `scripts/`
- **`bun run typecheck`** — TS only
- **`bun run test`** — Turbo tests
- **`bun run build`** — Turbo build
