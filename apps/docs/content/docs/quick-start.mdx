## Prerequisites

- Bun `1.4.2` (pinned in `packageManager`)
- Git
- An Android or iOS device or emulator with a development build of the app
- Optional: Docker Compose (Postgres), Python 3 + uv (AI service)

## 1) Install dependencies

```bash
bun install
```

## 2) Install git hooks (recommended)

```bash
bun run prepare
```

This enables Lefthook checks for formatting, linting, type checks, and commit hygiene.

## 3) Run the workspace

```bash
bun run dev
```

Turbo starts every app's dev server: Metro, the Nest API, the AI service (needs uv), the docs and
the landing page. The API needs Postgres: run `docker compose up -d postgres` first (see
[Docker](/docs/docker)).

## 4) Open apps

- Mobile app (`apps/mobile`): Metro on http://localhost:8081, opened from the development build
- Nest API (`apps/nest-api`): http://localhost:4000/api/v1/health, Swagger at `/api/docs`
- Docs (`apps/docs`): http://localhost:3002/docs
- AI service (`apps/ai-api`): http://localhost:8000
- Landing page (`apps/web`): http://localhost:3000

## 5) Validate quality before pushing

```bash
bun run preflight
```

`preflight` runs lint, typecheck and tests.

If your change only touches one app, you can still run checks at the root to keep CI consistent.
